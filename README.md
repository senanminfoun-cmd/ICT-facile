# ICT Facile

Application mobile (PWA) pour mesurer l'index cardio-thoracique (ICT) sur la photo d'une radiographie thoracique de face (PA) prise sur négatoscope.

- Fonctionne hors ligne une fois installée (Android et iPhone).
- Photo depuis l'appareil ou la galerie, masquage des noms, points déplaçables, ICT et diamètres en mm (calibrage sur la largeur du film).
- Signale les mesures impossibles ou peu fiables.
- Historique et annotations stockés uniquement sur le téléphone.

**Outil d'aide à la mesure, non certifié comme dispositif médical.** Le radiologue reste seul responsable de l'interprétation.

## Installer
Ouvrir https://senanminfoun-cmd.github.io/ict-facile/ puis :
- Android (Chrome) : menu ⋮ → « Installer l'application » / « Ajouter à l'écran d'accueil ».
- iPhone (Safari) : bouton Partager → « Sur l'écran d'accueil ».
